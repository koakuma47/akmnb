AKM Launcher G1.1 发布说明
====================================

一、这是什么
  一个 Windows 平台的 Minecraft 启动器，单文件 EXE，内置依赖，无需安装 Python。
  界面可选 5 套风格（默认矢量风），功能偏「实用工具」路线。

二、主要功能
  1. 微软正版登录（设备代码流）+ 离线模式
  2. 一键安装：原版 + 模组加载器一次装完（不会下两次）
  3. 下载详情窗口：实时看每个文件在下什么、下到多少
  4. 五语言界面 + 外置语言包 + 阿拉伯语连写/RTL
  5. 模组战备架、模组加载器、整合包、版本隔离、光影材质、四个小游戏
  6. 模组版本体检：拖入 jar + 目标版本 -> 筛出有对应版本的模组

五、上一版（B0.3）：修复 NeoForge 安装失败

  [ 修复 ] NeoForge 安装器一启动就失败（exit 1）
  - 根因：Forge / NeoForge 安装器要求目标 .minecraft 目录里有
    launcher_profiles.json（官方启动器生成的那个文件），没有就直接报
      There is no minecraft launcher profile in "...", you need to run the launcher first!
    然后 exit 1。AKM 的档案存在自己的 config.json 里，全新的游戏目录里没有这个文件，
    所以每台新机器装 NeoForge 都必然失败
  - 现在安装前会自动补建一个最小的 launcher_profiles.json（已存在则原样不动），
    Forge / Fabric / Quilt 走同一条前置检查
  - 实测：同一台机器、同样的网络，补建后安装器一路跑到
      Downloading library ... / Download completed: Checksum validated.
    并写出 versions/neoforge-21.1.265/neoforge-21.1.265.json + libraries/net/neoforged

  [ 改进 ] 安装器失败时的提示
  - 自动保存安装器日志到 logs/neoforge-<版本>-<时间>.log，错误框里直接给出路径
  - 按日志内容分类提示：
      缺 launcher_profiles.json / Java 版本太低 / maven.neoforged.net 连不上
    不再一律套用「可能是网络问题」
  - 错误框保留最后 900 字符的安装器输出，方便直接贴出来排查

  [ 说明 ] maven.neoforged.net 慢的情况
  - 部分网络到 maven.neoforged.net 会 30 秒连接超时，安装器会自动重试，
    安装会变慢（几分钟）但能装完
  - 安装器自带的 --mirror 参数只作用于 Mojang 的库，不会把 NeoForge 自己的
    maven 换到 BMCLAPI，所以这里没有开它，避免多一次无用的尝试
  - 如果日志里全是 UnknownHost / Connection refused，可用 [ NeoForge 官网 ]
    手动下载安装器双击运行

六、上一版（B0.2）：一键更新全部 + CurseForge 移植检测

  [ 新增 ] 一键更新全部
  - 体检结果里凡是有「目标版本上的更新构建」的模组，按钮直接带数量：
    [ 一键更新全部 (3) ]
  - 点一下确认后 4 路并发下载、校验 SHA1、替换旧 jar，装完自动重新体检

  [ 新增 ] CurseForge 移植版本检测（默认开启）
  - 体检时对「Modrinth 上这个 MC 版本没有构建」的模组，再去 CurseForge 查一遍
  - 命中就在结果表里显示成蓝色 [ CF ] 行：
      [ CF ] Just Enough Items  15.74.0.232  FABRIC  CurseForge 移植版：jei-1.20.1-fabric-15.74.0.232.jar
  - 体检结束自动弹窗：「有 N 个模组在 MC x 上没有原版构建，但 CurseForge 上有移植版本」，
    列出文件名对照；确认后直接下载进当前 mods（大小校验，原 jar 保留），装完自动重新体检
  - 面板上也有常驻的 [ 下移植版 (N) ]，之前点了否随时能补装
  - 只查「没有命中」的模组（命中过的不会多跑请求），最多 40 个、4 路并发
  - 防误装：CurseForge 项目标题必须和本地模组名对得上（去掉括号/符号后互为子串），
    加载器也必须一致（Quilt 视作可以使用 Fabric 包），否则不认这一条

  [ 说明 ] 数据来源
  - CurseForge 官方 API 要私有 Key，这里改用公开的 cfwidget 镜像读项目文件列表，
    下载走 edge.forgecdn.net 直链，玩家不需要填任何 Key

上一版（v1.5rc4）：原版下载提速 + 下载取消

  [ 修复 ] 找到「下载原版特别慢」的真正原因
  - BMCLAPI 的资源对象地址应该是 /assets/<前两位>/<hash>，
    旧版本写成了 /assets/<hash>，所以 3000 多个资源每个都要：
    先吃一个 404 -> 原地重试一次 -> 再 sleep 0.6 秒 -> 最后才回落官方源
  - 单是这个 bug，就白等了 3000 x 0.6 秒以上（12 线程并行也要好几分钟）
  - 现在地址写对了：镜像一次命中，不再无谓回落官方

  [ 提速 ] 下载引擎重写
  - 每个工作线程复用一条 TLS 长连接（keep-alive），
    不再为几千个小文件重复三轮握手
  - 并发提高：库文件 8 -> 12 路，资源对象 12 -> 24 路
  - 404 / 403 这种「明确答案」立刻切下一个源，不再重试 + 等待
  - 新增「源健康度」：某个源连续失败 6 次，本次安装直接跳过它，
    不再让 3000 个文件反复撞同一个坏源
  - 单文件超时收紧：资源 25s / 库 60s / 客户端 90s，
    卡死的连接不会再把工作线程钉住一分钟
  - 自动跟随 301/302 跳转（BMCLAPI 会把资源重定向到 CDN）
  - 状态栏实时速度：ASSETS // 1200 / 3598 // 42.5/s
    、CLIENT JAR // 6.2 MB / 22.1 MB // 1.8 MB/s

  [ 新功能 ] 取消原版下载（玩家确认后立即终止）
  - 下载窗口底部四个按钮：刷新清单 / 开始下载 / 取消下载 / 关闭
  - [ 取消下载 ] 只在下载进行中可点；点击先弹确认框：
    正在下载的文件会立即停止 / 已经下载好的文件会保留 /
    之后可以重新点 [ 开始下载 ] 继续
  - 确认后状态变 CANCELLING // 正在停止下载，请稍候 ...，
    下载线程在当前 256 KiB 数据块结束时退出（实测 1~2 秒停下，
    正在下 20 MB 的客户端 jar 也一样快）
  - 已下载的文件全部保留，.part 临时文件自动清理；
    重新开始时会跳过已完成的部分
  - 停下后状态写 CANCELLED // 已取消，已下载文件保留，可重新开始，
    按钮恢复可用，日志一行「玩家确认取消 // 正在终止原版下载 ...」
  - [ 关闭 ] 在下载中走同一个确认流程，不会偷偷关窗留下后台任务
  - 状态栏 [ 终止下载 ] 和菜单「游戏 -> 终止当前任务」都会先确认再终止，
    四个入口行为一致

十二、第一次使用（3 步）
  1. 把 AKM_Launcher.exe 放到一个你有写权限的文件夹里（建议单独建目录）
  2. 双击运行。首次启动会自动在同目录创建 .minecraft\ 与 config.json
  3. 点 [ 下载原版 ] 选版本 -> 装完自动选中 -> 点 [ IGNITE 点火起飞 ]
     要玩模组：再点 [ 模组加载器 ] 装 Forge/NeoForge/Fabric/Quilt

十三、目录与数据
  .minecraft\versions\   已安装版本（含导入的整合包 PACK-xxx）
  .minecraft\mods\       全局模组（未开启版本隔离时）
  .minecraft\shaderpacks\ 光影（[游戏] -> [光影 / 材质] -> 光影下载）
  .minecraft\resourcepacks\ 材质包（[游戏] -> [光影 / 材质] -> 材质包下载）
  .minecraft\runtime\    Mojang 运行时 + 内置 Java
  config.json            设置（可删，会重新生成）
  auth.json              登录令牌（首次登录后生成，请勿分享）
  logs\                  启动日志与自检日志

  所有下载都进 EXE 同目录的 .minecraft，不会写系统盘其它位置。
  删掉 config.json 与 .minecraft 即可恢复出厂状态。

十四、常见问题
  Q: 杀毒软件报毒 / SmartScreen 拦截？
  A: EXE 若未做代码签名，PyInstaller 打包的程序常被误报。
     可核对本说明附带的 SHA256，或选择「仍要运行」。
  Q: 提示缺少 Java？
  A: [游戏] -> [Java 运行时管理] 选 Java 21 下载；或自行安装 Java 21 后重启。
  Q: 网络连不上 / 下载很慢？
  A: 1.4b4 起下载源默认就是 BMCLAPI 镜像，一般不用再改。
     如果在海外，可在 [设置] -> [下载源] 切到「官方优先」。
  Q: 模组装上没生效？
  A: 看左侧版本信息是否显示 ISO（开启隔离时模组在 versions\<版本>\mods），
     或确认右侧版本栏选择的是你实际启动的版本。
  Q: 光影 / 材质包装上没生效？
  A: 光影需要 Iris 或 OptiFine，装上对应的光影加载器版本才会出现在
     `选项 -> 视频设置 -> 光影`；材质包在 `选项 -> 资源包` 里手动启用。
     若开启了版本隔离，请确认下载时的目标目录（窗口里的
     `装入全局 .minecraft` 复选框）与实际启动的实例一致。
  Q: 自动更新怎么开？
  A: [设置] -> [自动更新设置]，填入发布方提供的 update JSON 地址。
     清单格式见 update.example.json。
