## 怎么用

1. 下载上面的 zip，解压到任意文件夹（别放在需要管理员权限的目录）
2. 双击 `AKM_Launcher.exe`
3. 登录：正版点 `[ 微软登录 ]` 按提示走；没有正版就切离线模式，填个名字
4. 左侧选版本 → `[ 下载 / 安装 ]` 装游戏 → 装好后点 `[ 点燃起飞 ]`
5. 装模组：右边「模组战备架」里翻热门榜或搜索，挑好后 `[ 装配所选 ]`

需要 Java 21，启动器会自己找；找不到可以在设置里手动指定 `javaw.exe`。
